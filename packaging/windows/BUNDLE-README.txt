Media Launcher for Windows 10/11 x64

Run media-launcher.exe. libmpv, yt-dlp and Deno are included.
To browse videos: media-launcher.exe --root "C:\Users\You\Videos"
To locate your configuration and plugins: media-launcher.exe --show-paths
config.example.toml is a reference; it is not loaded from this folder.

Add media-launcher.exe as a non-Steam game, using its folder as Start In.
The ZIP uses normal per-user configuration, not a portable user-data directory.

Updates: close Media Launcher and run the newer installer, or replace your ZIP
folder at the same path. Settings/plugins remain outside this folder.
There are no automatic application or dependency updates in this version.
